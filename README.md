# Learnpl.com

A playful, interactive flashcard app for learning Polish vocabulary through repetition.

**[Visit Learnpl.com](https://learnpl.com)**

## About

Learnpl.com helps users build their Polish vocabulary through simple, low-effort practice. Words are organized into five categories and learned through a rolling set of flashcards that gradually introduces new vocabulary as progress is made.

Built to solve a real learning problem while improving my web development skills and showcasing my abilities.

## Features

- **Five vocabulary categories:** People, Actions, Things, Qualities, and Links.
- **Two learning directions:** Practice Polish to English or English to Polish, each with separate session progress.
- **Adaptive flashcards:** Start with 15 randomly selected words and introduce new words as progress is made.
- **Progress-based repetition:** Correct answers count immediately. After an incorrect answer, the word must be answered correctly twice in a row to count as progress.
- **Flexible Polish input:** Polish diacritics can be omitted when entering answers.
- **Playful animations:** Animated feedback for correct and incorrect answers, plus interactive flowers that grow and rotate on hover.
- **Responsive design:** Colorful, bison-themed interface for desktop and mobile.

## Tech Stack

- **HTML** — Structure
- **CSS** — Styling, responsive layout, and animations
- **JavaScript** — Flashcard logic, answer validation, and progress tracking
- **JSON** — Vocabulary data

## Progress Tracking

Progress is maintained during the active study session and separately for each learning direction. It is not permanently saved, so starting a new session provides another opportunity to practise the vocabulary.
